# ML-based-discovery-of-interactions
A workflow for screening interactions between polygenic risk score and clinical risk factors

# Description
This repository contains example code for:
- Data preprocessing and hyperparameter tuning
- XGBoost model training
- Friedman H-statistic interaction analysis
- SHAP value and SHAP interaction analyses

# Algorithms and software
## ML algorithms 
- Gradient boosting machine: [LightGBM v4.5.0] (https://github.com/microsoft/LightGBM) 
- Extreme gradient boosting: [XGBoost v2.1.4] (https://github.com/dmlc/xgboost) 
- Gradient boosting machine: [LightGBM v4.5.0] (https://github.com/microsoft/LightGBM)
## Interpretable ML 
- Friedman’s H-statistic: [artemis v0.1.5] (https://github.com/pyartemis/artemis) 
- Shapley additive explanations: [SHAP v0.46.0] (https://github.com/shap/shap) 
- Restricted cubic splines: [interactionRCS v0.1.1] (https://github.com/cran/interactionRCS) 
## Python modules for ML
- Causal discovery graph: [causal-learn v0.1.4.8] (https://github.com/py-why/causal-learn)
- [scikit-learn v1.5.2] (https://github.com/scikit-learn/scikit-learn)
